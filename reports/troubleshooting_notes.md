# Troubleshooting Notes

Use this table against real logs first, then update reports with the actual failure evidence. Commands assume the repository root and Docker Compose service names from `docker-compose.yml`.

| Symptom | Likely root cause | Verification command | Expected evidence | Fix | Prevention |
|---|---|---|---|---|---|
| gNB cannot connect to AMF | Wrong AMF address, AMF not running, or port binding issue | `docker compose logs --no-color gnb amf | grep -Ei "sctp|ng setup|connect|error"` | gNB repeats connection attempts; AMF has no NG setup | Confirm `configs/ueransim/gnb.yaml` uses `10.45.0.20:38412`; restart AMF and gNB | Keep static lab IPs aligned across Compose and configs |
| SCTP association failure | Host/kernel or Docker path does not support SCTP correctly | `sudo modprobe sctp || true; lsmod | grep sctp; docker compose logs --no-color gnb` | SCTP errors, no association established, no NG setup | Run on Ubuntu Linux/VM; avoid relying on Docker Desktop for final validation | Record host SCTP check in evidence before runtime testing |
| UE registration rejected | Subscriber missing or SUPI mismatch | `docker compose logs --no-color amf ue | grep -Ei "imsi|supi|unknown|reject|registration"` | AMF rejects or cannot find `imsi-001010000000001` | Provision subscriber using `./scripts/add_subscriber.sh` or version-correct Open5GS WebUI/DB method | Keep `configs/subscriber_config.yaml` as the source of truth |
| Authentication failure | K, OPc, AMF, or OP/OPc mode mismatch | `docker compose logs --no-color amf ue | grep -Ei "auth|mac|opc|failure|reject"` | Authentication failure or MAC failure around NAS auth | Match K/OPc/AMF in UE config and Open5GS subscriber DB | Never edit UE credentials without updating subscriber provisioning notes |
| Security mode failure | Unsupported or mismatched NAS integrity/ciphering algorithms | `docker compose logs --no-color amf ue | grep -Ei "security mode|NIA|NEA|reject|failure"` | Authentication succeeds but security mode reject/failure appears | Use conservative algorithms already in `amf.yaml` and `ue.yaml`; retry after clean restart | Keep NIA/NEA changes small and documented |
| DNN mismatch | UE requests a DNN that SMF/subscriber does not allow | `grep -R "internet" configs; docker compose logs --no-color smf amf ue | grep -Ei "dnn|apn|pdu|reject"` | PDU session reject or missing DNN in SMF logs | Align DNN across UE session, SMF session, subscriber DB, and reports | Treat DNN as a test parameter and change it in all locations together |
| S-NSSAI mismatch | SST/SD differs between UE, AMF, SMF, or subscriber | `grep -R "sst\\|sd\\|nssai" configs; docker compose logs --no-color amf smf ue | grep -Ei "nssai|slice|sst|sd|reject"` | Slice not supported or PDU session rejected | Align SST `1` and SD `000001` across configs and DB | Quote SD values to avoid leading-zero ambiguity |
| PDU session fails after registration | SMF cannot select UPF, DNN/slice rejected, or PFCP problem | `docker compose logs --no-color smf upf amf | grep -Ei "pdu|pfcp|upf|session|reject|fail"` | Registration complete exists, but no PDU accept | Check SMF `pfcp.client.upf`, UPF service status, DNN, and slice | Validate registration and PDU session separately in the checklist |
| UE gets no tunnel interface | PDU session did not complete or `/dev/net/tun`/privileges missing | `docker compose exec ue ip link; docker compose logs --no-color ue | grep -Ei "tun|uesimtun|pdu|error"` | No `uesimtun0`; UE may still show registration logs | Run UE with `privileged`/`NET_ADMIN` and `/dev/net/tun`; fix PDU reject first | Check `/dev/net/tun` before starting the lab |
| Ping fails despite session establishment | UE route, UPF forwarding, N6 NAT, or external target issue | `docker compose exec ue ip route; ./scripts/traffic_test.sh` | UE has tunnel/IP but ping packet loss is 100% | Verify UPF route/NAT and use a reachable target; test local DN path if Internet is blocked | Store UE route and traffic output in evidence |
| UPF route/NAT missing | Container image does not install NAT/forwarding rules automatically | `docker compose exec upf ip route; docker compose exec upf iptables -t nat -S || true` | UE subnet exists but no MASQUERADE/N6 route | Add host/container NAT rule appropriate to the image and host network policy | Document host-specific N6 changes in evidence notes |
| Docker network conflict | Static subnet overlaps existing Docker/VPN network | `docker network ls; docker network inspect open5gs-core-net open5gs-data-net` | Compose network creation fails or traffic routes unexpectedly | Change `10.45.0.0/24`, `10.46.0.0/24`, and matching config IPs together | Check `docker network inspect` and VPN routes before running |
| MongoDB/Open5GS DB issue | MongoDB unhealthy, old volume data, or dbctl version mismatch | `docker compose ps mongodb; docker compose logs --no-color mongodb open5gs-dbctl` | MongoDB unhealthy or dbctl command not found/unsupported | Restart MongoDB; inspect `open5gs-dbctl --help`; use WebUI/manual DB method if needed | Export evidence before deleting volumes; pin working image versions later |
| macOS Docker Desktop limitation | SCTP, TUN, or privileged networking is virtualized differently | `uname -s; docker compose logs --no-color gnb ue upf` | Partial startup but SCTP/TUN/user plane failure | Use Ubuntu VM or bare-metal Linux for validation | README should keep macOS marked as edit/parser-only unless proven otherwise |
| Parser reports missing events | Logs are incomplete, component names differ, or procedure failed | `python3 scripts/parse_attach_logs.py logs/*sample.txt -o /tmp/events.csv` | `missing_events` or many `unclassified_relevant` rows | Parse complete timestamped logs; inspect source file/line number columns; extend patterns only with real examples | Keep sample logs small, but tune parser against real logs |
| Port already in use | Local process occupies NRF/AMF exposed ports | `sudo ss -ltnp | grep -E ':7777|:38412' || true` | Compose cannot bind published port | Stop conflicting service or adjust host port mapping | Run host port check before `./scripts/start_lab.sh` |
